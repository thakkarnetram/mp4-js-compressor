# 🎬 MP4 Bulk Compressor

A  Node.js tool to **compress bulk MP4 files locally** with decent quality and reduced size — 
reliable and more private than online sites.

---

# How to use

- Clone the repo
- `npm i` to install all the dependencies 
- Download `ffmpeg` on your machine to compress locally 
- open terminal / cli and run `node index.js`

---

Refer the table for quality adjustment 

| CRF Value | Quality   | File Size |
| --------- | --------- | --------- |
| 18–22     | Very High | Large     |
| 23–27     | Balanced  | Medium    |
| 28–32     | Lower     | Small     |
